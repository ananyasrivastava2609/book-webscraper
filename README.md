# Web Scraper Project

## Objective
This project extracts book data from a website using Python web scraping techniques.

## Features
- Scrapes book titles
- Scrapes book prices
- Stores data in CSV format
- Stores data in JSON format
- Uses BeautifulSoup and requests

## Technologies Used
- Python
- requests
- BeautifulSoup4
- CSV
- JSON

## Website Used
https://books.toscrape.com/
